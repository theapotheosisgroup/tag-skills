# Starter due-diligence request list

A starting point for step 2 of the diligence procedure, not a standard: keep what applies to the transaction, drop the rest, and add what the deal needs. Each line becomes one request (expectation) with a category, a priority and a due date set when raised. Periods default to the last three financial years and the current year to date.

| Category | Request |
| --- | --- |
| Corporate | Articles, by-laws and any shareholder or unanimous shareholder agreement |
| Corporate | Minute book: board and shareholder resolutions and minutes |
| Corporate | Capitalization table, securities register, options, warrants and convertible instruments |
| Corporate | Organization chart of all entities, with ownership percentages |
| Financial | Annual financial statements (audited or reviewed) and the auditor's or reviewer's reports |
| Financial | Monthly management accounts and trial balances for the year to date |
| Financial | Budget and forecast for the current and next year, with assumptions |
| Financial | Accounts receivable and payable agings at the latest month-end |
| Financial | Debt, credit facilities, guarantees, security and covenant compliance certificates |
| Tax | Income tax returns and notices of assessment |
| Tax | Sales tax returns and any audits, disputes or voluntary disclosures |
| Contracts | Material customer and supplier agreements, with change-of-control and exclusivity terms |
| Contracts | Leases for all premises and equipment |
| People | Employee list with role, start date, compensation and status (anonymized where required) |
| People | Employment agreements for officers and key employees; benefit and incentive plans |
| Intellectual property | Registered and pending IP, licences in and out, and assignment agreements |
| Litigation | Pending or threatened claims, demand letters and settlements |
| Regulatory | Licences, permits and material correspondence with regulators |
| Privacy and IT | Privacy policies, data-processing agreements, security incidents and key systems |
| Insurance | Policies in force and the claims history |
